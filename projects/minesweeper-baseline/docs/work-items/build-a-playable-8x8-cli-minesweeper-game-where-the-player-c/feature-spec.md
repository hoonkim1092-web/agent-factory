## Feature Overview

8×8 고정 격자 위에서 플레이어가 셀을 공개하고 지뢰를 깃발로 표시하는 단일 터미널 세션 지뢰찾기 게임을 구현한다. 외부 패키지 의존 없이 Python 3.11 표준 라이브러리만 사용하며, Agent Factory 병렬 작업 측정 파이프라인의 기준 태스크(baseline)로 활용된다.

- **엔트리포인트**: `minesweeper.py` — `python3 minesweeper.py [--mines N]`
- **아키텍처 스타일**: CLI (단일 프로세스, 동기 입력 루프)
- **실행 환경**: Python 3.11, stdlib only (`random`, `sys`, `os`)
- **테스트 도구**: pytest 7.x (개발 전용, 런타임 비포함)

## User Scenarios

### 시나리오 1 — 정상 게임 흐름 (승리)

1. 사용자가 `python3 minesweeper.py` 또는 `python3 minesweeper.py --mines 10`을 실행한다.
2. 시스템이 8×8 빈 보드(`?` 또는 `.` 표시)와 좌표 입력 프롬프트를 출력한다.
3. 사용자가 `3 4`를 입력하면 해당 셀이 공개되고, 인접 지뢰 수가 표시된다. 인접 지뢰가 0이면 연쇄 공개된다.
4. 사용자가 `f 2 5`를 입력하면 (2, 5) 셀에 깃발(`F`)이 표시된다. 재입력 시 깃발이 해제된다.
5. 지뢰를 제외한 모든 셀이 공개되면 `축하합니다! 승리했습니다.` 메시지가 출력되고 프로그램이 종료된다.

### 시나리오 2 — 지뢰 밟음 (패배)

1. 사용자가 지뢰가 있는 셀의 좌표를 입력한다.
2. 시스템이 모든 지뢰 위치를 보드에 공개한 상태로 출력한다.
3. `게임 오버! 지뢰를 밟았습니다.` 메시지가 출력되고 프로그램이 종료된다.

### 시나리오 3 — 잘못된 입력

1. 사용자가 범위를 벗어난 좌표(`9 0`) 또는 형식 오류(`abc`) 입력을 한다.
2. 시스템이 오류 메시지를 출력하고 프로그램 종료 없이 재입력 프롬프트를 표시한다.

### 시나리오 4 — 이미 공개된 셀 재선택

1. 사용자가 이미 공개된 셀의 좌표를 입력한다.
2. 시스템이 `이미 공개된 셀입니다.` 안내를 출력하고 재입력을 요청한다.

### 시나리오 5 — 첫 클릭 안전 보장

1. 사용자가 첫 번째 좌표를 입력한다.
2. 해당 셀에 지뢰가 배치되지 않도록 지뢰 배치가 첫 클릭 후 수행된다.
3. 첫 클릭은 항상 안전하게 공개된다.

## Functional Requirements

### FR-01 보드 초기화

- 8×8 고정 크기 격자를 생성한다.
- 모든 셀의 초기 상태는 `미공개(unrevealed)`이다.
- 깃발 상태 초기값은 모두 `False`이다.

### FR-02 지뢰 배치 (safe-first-click)

- 지뢰 수는 `--mines N` 인자로 지정하며, 기본값은 `10`이다.
- `N`은 `1` 이상 `63` 이하여야 한다 (8×8 - 1).
- 지뢰는 **첫 번째 공개 요청 좌표 직후**에 무작위 배치된다.
- 첫 번째 공개 셀은 지뢰 배치 대상에서 제외된다.

### FR-03 인접 지뢰 수 계산

- 지뢰가 없는 각 셀은 상하좌우 및 대각선 8방향 인접 셀의 지뢰 수를 `adjacent_count`로 저장한다.
- 지뢰 배치 완료 후 전체 보드에 대해 일괄 계산한다.

### FR-04 셀 공개 (재귀 연쇄 공개)

- 사용자가 미공개·비깃발 셀의 좌표를 입력하면 해당 셀을 공개한다.
- `adjacent_count == 0`인 셀 공개 시, 인접한 미공개·비깃발·비지뢰 셀을 재귀적으로 연쇄 공개한다.
- 재귀는 격자 경계(0~7)를 넘지 않는다. 무한루프 방지를 위해 이미 공개된 셀은 재방문하지 않는다.
- 지뢰 셀 공개 시 즉시 `LOSE` 상태로 전환한다.

### FR-05 깃발 토글

- `f R C` 명령으로 `(R, C)` 셀의 깃발 상태를 토글한다.
- 이미 공개된 셀에는 깃발을 설정할 수 없다.
- 깃발이 설정된 셀은 공개 명령으로 공개되지 않는다.

### FR-06 승리 판정

- 지뢰가 없는 모든 셀이 공개된 시점에 `WIN` 상태로 전환한다.
- 승리 시 `축하합니다! 승리했습니다.` 메시지 출력 후 프로그램을 종료한다.

### FR-07 패배 판정

- 지뢰 셀이 공개된 시점에 `LOSE` 상태로 전환한다.
- 패배 시 모든 지뢰 위치를 보드에 표시한 후 `게임 오버! 지뢰를 밟았습니다.` 메시지 출력 후 프로그램을 종료한다.

### FR-08 보드 렌더링

- 매 턴마다 현재 보드 상태를 ASCII로 출력한다.
- 셀 표시 규칙:

| 상태 | 출력 문자 |
|------|-----------|
| 미공개 | `?` |
| 깃발 | `F` |
| 공개(지뢰 없음, count>0) | `1`~`8` |
| 공개(count==0) | `.` |
| 공개(지뢰, 패배 후) | `*` |

- 행 번호(0~7)와 열 번호(0~7)를 인덱스로 표시한다.

### FR-09 입력 파싱 및 검증

- 공개 명령: `R C` (정수 두 개, 공백 구분)
- 깃발 명령: `f R C`
- 종료 명령: `q` 또는 `quit`
- `R`, `C`는 `0~7` 범위의 정수여야 한다.
- 입력 오류 시 오류 메시지 출력 후 재입력 요청 (프로그램 종료 없음).

## Non-Functional Requirements

### NFR-01 의존성 제한

- 런타임 의존성: Python 3.11 표준 라이브러리만 허용 (`random`, `sys`, `os`).
- 서드파티 패키지(numpy, curses 등) 사용 금지.

### NFR-02 단일 세션 실행

- 단일 터미널 세션에서 게임 시작부터 종료까지 완결되어야 한다.
- 파일 저장, 네트워크 통신, 외부 프로세스 호출 없음.

### NFR-03 재현 가능성 (테스트용)

- `--seed N` 옵션으로 `random.seed(N)`을 설정하면 동일한 지뢰 배치가 재현된다.
- 지정하지 않으면 무작위 시드를 사용한다.

### NFR-04 종료 코드

- 정상 종료(승리/패배/사용자 quit): exit code `0`.
- 인수 오류(예: `--mines abc`): exit code `2`.

## Inputs and Outputs

### 입력

| 소스 | 형식 | 설명 |
|------|------|------|
| CLI 인수 | `--mines N` | 지뢰 수 (기본: 10) |
| CLI 인수 | `--seed N` | 난수 시드 (선택) |
| stdin | `R C` | 셀 공개 명령 |
| stdin | `f R C` | 깃발 토글 명령 |
| stdin | `q` / `quit` | 게임 종료 |

### 출력

| 출력처 | 형식 | 설명 |
|--------|------|------|
| stdout | ASCII 보드 | 매 턴 보드 상태 렌더링 |
| stdout | 프롬프트 문자열 | 입력 안내 메시지 |
| stdout | 결과 메시지 | 승리/패배/오류 안내 |

## Exceptions and Failure Scenarios

### EX-01 범위 초과 좌표

- **조건**: 입력 좌표 `R` 또는 `C`가 `0~7` 범위를 벗어남.
- **처리**: `유효하지 않은 좌표입니다. 0~7 사이의 정수를 입력하세요.` 출력 후 재입력 요청.

### EX-02 형식 오류 입력

- **조건**: 정수로 변환 불가능한 입력 (`abc`, `3.5` 등).
- **처리**: `입력 형식이 올바르지 않습니다. 예: 3 4` 출력 후 재입력 요청.

### EX-03 이미 공개된 셀 선택

- **조건**: 이미 공개된 셀의 좌표를 공개 명령으로 입력.
- **처리**: `이미 공개된 셀입니다.` 출력 후 재입력 요청.

### EX-04 깃발 설정 불가 셀

- **조건**: 이미 공개된 셀에 `f R C` 명령 입력.
- **처리**: `공개된 셀에는 깃발을 설정할 수 없습니다.` 출력 후 재입력 요청.

### EX-05 지뢰 수 범위 오류

- **조건**: `--mines N`에서 `N < 1` 또는 `N > 63`.
- **처리**: `지뢰 수는 1 이상 63 이하여야 합니다.` 출력 후 exit code `2`로 종료.

### EX-06 재귀 공개 경계 침범 방지

- **위험**: 연쇄 공개 재귀 중 격자 외부 셀 접근 시도.
- **처리**: 모든 재귀 호출 전 `0 <= r < 8` 및 `0 <= c < 8` 조건 검사. 조건 불만족 시 해당 방향 탐색 중단.

## Existing Behavior To Preserve

- 이 프로젝트는 신규 구현이므로 보존해야 할 기존 동작이 없다.
- `minesweeper.py`가 이미 존재하는 경우, 기존 파일의 공개 함수 시그니처(`reveal_cell`, `toggle_flag`, `check_win`, `check_lose`)를 변경하지 않는다.

## Acceptance Criteria

### AC-01 게임 실행

> `python3 minesweeper.py` 실행 시 8×8 보드가 출력되고 입력 프롬프트가 표시된다.

### AC-02 기본 지뢰 수

> `--mines` 인수 없이 실행 시 지뢰 수가 정확히 10개임을 `--seed N` 고정 후 보드 검사로 확인한다.

### AC-03 첫 클릭 안전 보장

> `--seed N` 고정 상태에서 임의 셀을 첫 번째 공개 명령으로 지정했을 때 해당 셀이 지뢰가 아님을 단위 테스트로 확인한다.

### AC-04 연쇄 공개

> `adjacent_count == 0`인 셀 공개 시 인접 빈 영역이 모두 연쇄 공개되며, 공개 범위가 격자 경계(0~7)를 초과하지 않는다.

### AC-05 깃발 토글

> `f R C` 명령 후 보드에 `F`가 표시되고, 동일 좌표 재입력 시 `F`가 `?`로 복원된다.

### AC-06 패배 판정 및 지뢰 공개

> 지뢰 셀 공개 시 모든 지뢰 위치에 `*`가 표시되고 `게임 오버!` 메시지 후 exit code `0`으로 종료된다.

### AC-07 승리 판정

> 비지뢰 셀 전체 공개 시 `축하합니다! 승리했습니다.` 메시지 후 exit code `0`으로 종료된다.

### AC-08 입력 오류 복원

> 범위 초과 좌표 및 형식 오류 입력 시 게임이 종료되지 않고 오류 메시지와 함께 재입력 프롬프트가 표시된다.

### AC-09 지뢰 수 범위 오류

> `--mines 0` 또는 `--mines 64` 실행 시 오류 메시지 출력 후 exit code `2`로 종료된다.

### AC-10 단위 테스트 통과

> `pytest tests/` 실행 시 모든 테스트가 PASS이며, 다음 시나리오를 최소 1개 이상의 실행 경로(비mock)로 포함한다:
> - `adjacent_count` 정확성
> - 재귀 공개 경계 안전성
> - safe-first-click 보장
> - WIN 상태 전환
> - LOSE 상태 전환
