## 1. 화면 흐름

### 1.1 게임 상태 전이 다이어그램

```
[프로그램 시작] → 게임 초기화(보드 생성, 지뢰 미배치)
      ↓
[화면: 게임 시작] — 빈 보드(전체 ?) + 입력 프롬프트
      ↓
[입력 대기 루프]
      ├─ 유효 공개 명령 (R C)
      │     ├─ 첫 번째 공개 → 지뢰 배치 후 공개 처리
      │     ├─ 이후 공개 → 공개 처리
      │     │     ├─ 상태 = PLAYING → [화면: 턴 갱신] → 입력 대기 루프
      │     │     ├─ 상태 = WIN    → [화면: 승리] → 프로그램 종료 (exit 0)
      │     │     └─ 상태 = LOSE   → [화면: 패배] → 프로그램 종료 (exit 0)
      ├─ 유효 깃발 명령 (f R C) → 깃발 토글 → [화면: 턴 갱신] → 입력 대기 루프
      ├─ quit / q → 종료 메시지 → 프로그램 종료 (exit 0)
      └─ 오류 입력 → 오류 메시지 출력 → 보드 재출력 없음 → 입력 대기 루프
```

### 1.2 화면 출력 순서

각 화면 전환 시 아래 순서를 **정확히** 따른다.

#### 화면 A — 게임 시작 (프로그램 최초 출력)

```
(빈 줄 1개)
지뢰찾기 8×8 [지뢰: {n}개]
   0 1 2 3 4 5 6 7
0  ? ? ? ? ? ? ? ?
1  ? ? ? ? ? ? ? ?
2  ? ? ? ? ? ? ? ?
3  ? ? ? ? ? ? ? ?
4  ? ? ? ? ? ? ? ?
5  ? ? ? ? ? ? ? ?
6  ? ? ? ? ? ? ? ?
7  ? ? ? ? ? ? ? ?
(빈 줄 1개)
명령 입력 (행 열 / f 행 열 / q): (커서)
```

#### 화면 B — 턴 갱신 (공개 또는 깃발 처리 후, PLAYING 상태)

```
--------------------
지뢰찾기 8×8 [지뢰: {n}개]
   0 1 2 3 4 5 6 7
{갱신된 보드 8행}
(빈 줄 1개)
명령 입력 (행 열 / f 행 열 / q): (커서)
```

#### 화면 C — 패배 (LOSE 상태)

```
--------------------
지뢰찾기 8×8 [게임 오버]
   0 1 2 3 4 5 6 7
{모든 지뢰가 * 로 표시된 보드 8행}
(빈 줄 1개)
게임 오버! 지뢰를 밟았습니다.
```

#### 화면 D — 승리 (WIN 상태)

```
--------------------
지뢰찾기 8×8 [승리!]
   0 1 2 3 4 5 6 7
{최종 보드 8행}
(빈 줄 1개)
축하합니다! 승리했습니다.
```

#### 화면 E — 오류 입력 (보드 재출력 없음)

```
{오류 메시지 1줄}
명령 입력 (행 열 / f 행 열 / q): (커서)
```

#### 화면 F — 사용자 종료 (quit / q)

```
게임을 종료합니다.
```

## 2. 보드 렌더링 포맷

### 2.1 헤더 라인

상태별 헤더 문자열:

| 게임 상태 | 헤더 문자열 |
|-----------|-------------|
| PLAYING | `지뢰찾기 8×8 [지뢰: {n}개]` |
| LOSE | `지뢰찾기 8×8 [게임 오버]` |
| WIN | `지뢰찾기 8×8 [승리!]` |

- `{n}`은 현재 지뢰 수 정수 값으로 치환한다 (예: `10`).

### 2.2 열 레이블 라인

```
   0 1 2 3 4 5 6 7
```

- 앞에 공백 3개(`   `)를 둔다.
  - 공백 1개: 행 번호(1자리) 너비
  - 공백 2개: 행 번호와 첫 번째 열 사이 구분
- 열 번호 0~7은 공백 1개로 구분한다.

### 2.3 행 렌더링

```
{r}  {c0} {c1} {c2} {c3} {c4} {c5} {c6} {c7}
```

- `{r}`: 행 번호 (0~7, 1자리 정수, 오른쪽 정렬 불필요)
- 행 번호 뒤에 공백 2개
- 각 셀 기호는 공백 1개로 구분

예시:

```
   0 1 2 3 4 5 6 7
0  ? ? ? ? ? ? ? ?
1  . 1 ? F ? ? ? ?
2  . 1 1 1 ? ? ? ?
3  . . . . 2 ? ? ?
4  . . . . 1 F ? ?
5  . . . 1 1 ? ? ?
6  . . . 1 ? ? ? ?
7  . . . 1 ? ? ? ?
```

### 2.4 구분선

```
--------------------
```

- ASCII 하이픈(`-`) 20자를 사용한다.
- 구분선은 새 화면(턴 갱신·패배·승리) 출력 시 **보드 헤더 바로 직전**에 출력한다.
- 구분선 전후에 별도 빈 줄을 삽입하지 않는다.

## 3. 셀 기호 사전

| 셀 상태 | 기호 | 설명 |
|---------|------|------|
| 미공개 (unrevealed) | `?` | 아직 공개되지 않은 셀 |
| 깃발 (flagged) | `F` | 플레이어가 지뢰로 표시한 셀 |
| 공개 — 인접 지뢰 1개 이상 | `1`~`8` | 인접 지뢰 수 (1~8 정수) |
| 공개 — 인접 지뢰 0개 | `.` | 빈 셀 |
| 공개 — 지뢰 (패배 후만) | `*` | 지뢰가 있던 셀 (패배 화면에서만) |

### 기호 우선순위 및 규칙

1. 깃발이 설정된 셀은 패배 후에도 `F`로 유지한다 (지뢰 위치와 무관).
2. 패배 시 깃발 없이 미공개 상태인 지뢰 셀은 `*`로 전환한다.
3. 공개 명령이 실행되기 전까지 모든 셀은 `?` 또는 `F` 중 하나다.
4. 셀은 공개(revealed)되면 기호가 고정되며 이후 변경되지 않는다.

## 4. 메시지 문자열

모든 사용자 대면 문자열은 한국어(OS: `ko-KR`)로 작성한다.
Frontend Dev는 아래 문자열을 **정확히** 구현한다 (오탈자·띄어쓰기 포함).

### 4.1 결과 메시지

| 이벤트 | 메시지 원문 |
|--------|-------------|
| 승리 | `축하합니다! 승리했습니다.` |
| 패배 | `게임 오버! 지뢰를 밟았습니다.` |
| 사용자 종료 (quit) | `게임을 종료합니다.` |

### 4.2 오류 메시지

| 오류 코드 | 발생 조건 | 메시지 원문 |
|-----------|-----------|-------------|
| EX-01 | 좌표 `R` 또는 `C`가 0~7 범위를 벗어남 | `유효하지 않은 좌표입니다. 0~7 사이의 정수를 입력하세요.` |
| EX-02 | 정수로 변환 불가능한 입력 | `입력 형식이 올바르지 않습니다. 예: 3 4` |
| EX-03 | 이미 공개된 셀에 공개 명령 | `이미 공개된 셀입니다.` |
| EX-04 | 공개된 셀에 깃발 명령 | `공개된 셀에는 깃발을 설정할 수 없습니다.` |
| EX-05 | `--mines N`에서 N < 1 또는 N > 63 | `지뢰 수는 1 이상 63 이하여야 합니다.` |

- 오류 메시지는 표준 출력(stdout)에 출력한다.
- 오류 출력 후 보드를 재출력하지 않고 즉시 입력 프롬프트를 표시한다.

### 4.3 안내 메시지 (선택적)

안내 메시지는 의무 구현 사항이 아니다.
Frontend Dev 재량으로 포함할 수 있으나 AC 검증 기준에는 포함되지 않는다.

| 상황 | 메시지 형식 |
|------|-------------|
| 깃발 설정 | `(행 {r}, 열 {c})에 깃발을 설정했습니다.` |
| 깃발 해제 | `(행 {r}, 열 {c})의 깃발을 해제했습니다.` |

## 5. 입력 프롬프트

### 5.1 기본 프롬프트 문자열

```
명령 입력 (행 열 / f 행 열 / q): 
```

- 콜론(`:`) 뒤에 공백 1개가 있다.
- 개행 없이 커서가 같은 줄에 위치한다.
- Python `input()` 함수의 `prompt` 인자로 전달한다.

```python
cmd = input("명령 입력 (행 열 / f 행 열 / q): ")
```

### 5.2 입력 형식 요약

| 명령 | 입력 형식 | 예시 |
|------|-----------|------|
| 셀 공개 | `{행} {열}` | `3 4` |
| 깃발 토글 | `f {행} {열}` | `f 2 5` |
| 게임 종료 | `q` 또는 `quit` | `q` |

- 행과 열은 정수 0~7이다.
- 토큰은 공백으로 구분하며 앞뒤 공백은 `strip()`으로 제거한다.
- 대소문자 구분: `f`만 허용하며 `F`는 허용하지 않는다.
