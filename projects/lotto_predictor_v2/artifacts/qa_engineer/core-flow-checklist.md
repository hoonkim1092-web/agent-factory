## 입력 인터페이스
- 수집기 진입점 또는 실행 명령

- 빌드 산출물 경로
- 사용자 가이드 문서 경로

## 실행 슬라이스
### 1. 수집기 및 캐시 smoke
- [ ] 최신 회차 탐색 또는 지정 회차 수집 명령이 실행된다.
- [ ] 네트워크 성공 시 회차 데이터가 캐시에 반영된다.
- [ ] 이미 수집된 회차를 다시 요청해도 중복 저장 없이 종료된다.
- [ ] 실패 시 로그 또는 오류 메시지에 원인이 한국어로 기록된다.

### 2. 분석 엔진 결과 확인
- [ ] 최근 500회차 기준 입력이 비어 있지 않음을 확인한다.
- [ ] 번호별 빈도, 최근 50회 추세, 홀짝/구간 분포가 모두 출력되거나 구조화된 결과에 포함된다.
- [ ] 합계 또는 개수 검산이 가능한 핵심 수치가 누락되지 않는다.

### 3. 추천기 재현성 확인
- [ ] 동일 `seed`로 두 번 실행했을 때 5개 조합이 동일하다.
- [ ] 각 조합은 1~45 범위의 중복 없는 6개 숫자로 구성된다.
- [ ] 추천 결과에 전략 근거 또는 요약 지표가 포함된다.

### 4. 터미널 리포트 형식 확인
- [ ] 제목, 기준 회차 범위, 통계 요약, 추천 조합, 면책 고지 섹션이 존재한다.
- [ ] 한국어 문구가 깨지지 않고 출력된다.
- [ ] 당첨 보장 또는 오해 소지가 있는 표현이 없다.

### 5. 빌드 산출물 및 사용자 가이드 확인
- [ ] PyInstaller 산출물 경로가 존재한다.
- [ ] 산출물 실행 절차가 가이드 문서와 일치한다.
- [ ] macOS 또는 Windows 실행 시 주의사항이 가이드에 포함된다.

## 기록 규칙
- 각 체크 항목은 `PASS`, `FAIL`, `BLOCKED` 중 하나로 기록한다.
- 실패 시 관련 산출물 경로, 재현 파라미터, 관찰 결과를 함께 남긴다.
- verify 단계에서는 본 체크리스트를 기준으로 `verification-report.md`를 갱신한다.
