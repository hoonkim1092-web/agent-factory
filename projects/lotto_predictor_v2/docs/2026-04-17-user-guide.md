# 로또 패턴 예측기 사용자 가이드

> 한국 로또 6/45 최근 500회차 당첨번호를 분석해 패턴 기반 6숫자 조합 5개를 추천하는 데스크톱 도구

## 1. 개요

동행복권 공식 API에서 최근 500회차 1등 당첨번호를 수집하고, 아래 5가지 통계를 분석해 1~45 중 6개 번호 조합을 점수 순으로 추천합니다.

- **번호별 출현 빈도**
- **연속 등장 간격 (gap)**
- **회차별 홀짝 비율**
- **5개 구간 (1-10, 11-20, 21-30, 31-40, 41-45) 분포**
- **최근 회차 가중 트렌드**

> ⚠️ 본 도구는 통계적 패턴 분석 결과를 제공하며 당첨을 보장하지 않습니다.

## 2. 실행 방법

### 2.1 더블클릭 실행 (PyInstaller 단일 실행 파일)

1. GitHub Release 페이지에서 플랫폼에 맞는 파일을 다운로드
   - **Windows**: `lotto-predictor.exe`
   - **macOS/Linux**: `lotto-predictor`
2. 파일을 더블클릭 (또는 터미널에서 실행)
3. 실행 중간에 `캐시 보충` 메시지가 나올 수 있습니다 (초기 실행 시 API 호출)
4. 리포트 출력 후 `Enter` 키로 종료

### 2.2 소스로 실행

```bash
cd projects/lotto_predictor_v2
python -m lotto
```

또는

```bash
python src/lotto_predictor/__main__.py
```

## 3. 옵션

| 플래그 | 기본값 | 설명 |
|---|---|---|
| `-n, --count N` | 5 | 추천 조합 개수 |
| `-d, --draws N` | 500 | 분석에 사용할 최근 회차 수 |
| `--cache PATH` | `~/.lotto_cache/draws.json` | 캐시 JSON 파일 경로 |
| `--offline` | - | 네트워크 호출 없이 로컬 캐시만 사용 |
| `--pause` | - | 실행 끝에 Enter 대기 (더블클릭 실행용) |

### 예시

```bash
# 조합 10개 추천
python -m lotto -n 10

# 최근 300회차만 분석
python -m lotto -d 300

# 네트워크 차단 상태 (캐시만)
python -m lotto --offline

# 커스텀 캐시 경로
python -m lotto --cache /tmp/my_cache.json
```

## 5. 캐시 동작

- 기본 캐시: `~/.lotto_cache/draws.json` (홈 디렉토리)
- TTL: 24시간 — 만료 시 자동 재수집
- 파일 락: `fcntl` 기반 배타 락 (동시 실행 안전)
- 캐시 수동 삭제:
  ```bash
  rm -rf ~/.lotto_cache
  ```

## 6. 문제 해결

### 네트워크 오류
동행복권 API 응답이 없으면 자동으로 `--offline` 모드로 후퇴합니다. 캐시에 이전 데이터가 있으면 분석 가능합니다.

출력에 다음 라인이 보이면 캐시 fallback 중:
```
네트워크 연결 실패: ...
캐시 fallback 사용: 최근 저장 회차 500
실행 상태: degraded-success
```

### 파일 락 타임아웃
다른 실행 프로세스가 락을 쥐고 있으면 `CacheLockTimeoutError`가 발생합니다. 1~2초 후 재실행하세요.

### PyInstaller 빌드
```bash
pip install pyinstaller
pyinstaller --clean --noconfirm lotto-predictor.spec
# 산출물: dist/lotto-predictor (단일 실행 파일)
```
