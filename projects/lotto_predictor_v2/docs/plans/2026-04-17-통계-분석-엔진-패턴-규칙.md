## 설계 의도
- 최근 최대 500회차 당첨번호를 입력받아 추천기에서 재사용 가능한 순수 통계 함수를 제공한다.
- 분석 규칙을 빈도, 연속 등장 간격, 홀짝 비율, 구간 분포, 최근 트렌드 가중치로 고정한다.
- 입력 검증과 예외 메시지를 함수 내부에 포함해 상위 레이어가 잘못된 데이터를 조기에 식별할 수 있게 한다.

## 인터페이스 제안
### 입력
- `draws`: 최근 회차부터 과거 회차 순으로 정렬된 최대 500건의 회차 목록
- 각 항목은 아래 둘 중 하나를 허용
  - 길이 6의 정수 시퀀스
  - `numbers` 속성에 길이 6의 정수 시퀀스를 가진 객체

### 출력
- `calculate_number_frequency(draws) -> dict[int, int]`
- `calculate_consecutive_gaps(draws) -> dict[int, dict[str, object]]`
- `calculate_odd_even_ratio(draws) -> dict[str, object]`
- `calculate_section_distribution(draws) -> dict[str, int]`
- `calculate_trend_weights(draws) -> dict[int, float]`
- `analyze_patterns(draws) -> dict[str, object]`

## 구현 방침
1. 공통 입력 검증 헬퍼로 회차 구조, 숫자 범위, 중복, 건수 제한을 일관되게 검사한다.
2. 빈도와 구간 분포는 전체 회차 누적 합산으로 계산한다.
3. 연속 등장 간격은 회차 인덱스 차이 기반 간격 목록, 마지막 간격, 평균 간격을 함께 반환한다.
4. 홀짝 비율은 회차별 `홀수:짝수` 분포 집계와 대표 비율을 반환한다.
5. 트렌드 가중치는 입력 순서를 최신순으로 가정하고, 최신 회차일수록 큰 선형 가중치를 부여한다.

## 대안 검토
### 대안 A. 클래스 기반 분석기
- 장점: 상태를 묶어 캐시하기 쉽다.
- 단점: 현재 요구사항인 순수 함수 집합과 맞지 않고 테스트 경계가 흐려진다.
- 결론: 채택하지 않음.

### 대안 B. 함수형 모듈
- 장점: 추천기와 느슨하게 결합되고 단위 테스트가 단순하다.
- 단점: 공통 검증 코드가 반복될 수 있다.
- 결론: 채택. 공통 헬퍼로 중복을 줄인다.
