# 8인 네트워크 텍사스 홀덤 포커 — 게임 규칙 명세서

> 기준: WSOP (World Series of Poker) 공식 텍사스 홀덤 룰
> 적용 버전: 1.0.0 | 최종 갱신: 2026-05-07

---

## 1. Hand Rankings (핸드 순위)

순위는 높을수록 강하다. 동점 시 **킥커(kicker)** 규칙으로 최종 우열을 가린다.

| 순위 | 핸드명 | 조건 |
|------|--------|------|
| 1 | Royal Flush | A K Q J 10 동일 수트 |
| 2 | Straight Flush | 연속된 5장 동일 수트 (A-2-3-4-5 최하위) |
| 3 | Four of a Kind | 동일 숫자 4장 |
| 4 | Full House | 트리플 + 페어 |
| 5 | Flush | 동일 수트 5장 (연속 불필요) |
| 6 | Straight | 연속된 5장 다른 수트 (A-2-3-4-5 휠 허용) |
| 7 | Three of a Kind | 동일 숫자 3장 |
| 8 | Two Pair | 페어 2쌍 |
| 9 | One Pair | 페어 1쌍 |
| 10 | High Card | 해당 없음 — 가장 높은 단일 카드 |

### 킥커 규칙 (Kicker Rules)

- 모든 핸드는 **7장(홀 2장 + 커뮤니티 5장) 중 최강 5장** 조합으로 결정한다.
- 동일 핸드 등급끼리 비교 시: 핸드 구성 카드를 **높은 순서로 차례대로** 비교한다.
  - 예) One Pair K vs One Pair K → 킥커 비교 순서: 1st 킥커 → 2nd 킥커 → 3rd 킥커
  - 예) Full House (A-A-A-K-K) vs Full House (A-A-A-Q-Q) → 트리플 A로 동점 후 페어 K > Q
- 5장이 **완전히 동일**하면 팟을 균등 분할한다 (Split Pot).
- 수트(♠♥♦♣)는 순위 결정에 사용하지 않는다 — 수트 간 우열 없음.
- Flush 간 비교: 1번째 최고 카드부터 5번째까지 순서대로 비교한다.
- Straight / Straight Flush: A는 최고(A-K-Q-J-10)와 최저(A-2-3-4-5 = 5 하이) 모두 허용.

## 2. Blind Structure (블라인드 구조)

### 기본 블라인드 설정

- **스몰 블라인드 (Small Blind, SB)**: 10 chips
- **빅 블라인드 (Big Blind, BB)**: 20 chips
- **초기 칩**: 플레이어당 1,000 chips 고정 지급
- **최소 게임 참가 인원**: 2명 이상 (최대 8명)

### 버튼 로테이션 (Button Rotation)

- **딜러 버튼(D)**: 첫 게임 시 무작위 플레이어에게 배정.
- 매 핸드 종료 후 버튼은 **시계 방향으로 1칸** 이동한다.
- **2인 플레이(헤즈업)** 시 예외 규칙:
  - 딜러 버튼 = 스몰 블라인드 포지션
  - 빅 블라인드가 먼저 행동하며, 프리플랍에서는 딜러가 마지막 행동
- **플레이어 순서**: 버튼 → SB → BB → UTG → MP → CO → BTN (8인 기준 풀테이블)

### 포지션 정의 (8인 테이블)

| 포지션 | 약어 | 설명 |
|--------|------|------|
| Dealer Button | BTN | 허구의 딜러, 라운드에서 마지막 배팅 |
| Small Blind | SB | BTN 왼쪽, 강제 배팅 10 |
| Big Blind | BB | SB 왼쪽, 강제 배팅 20 |
| Under The Gun | UTG | BB 왼쪽, 프리플랍 첫 행동 |
| UTG+1 | UTG+1 | — |
| Middle Position | MP | — |
| Cut-Off | CO | BTN 오른쪽 |

### 블라인드 강제 포스팅 규칙

- SB·BB는 핸드 시작 전 **자동 차감**된다.
- 게임 도중 참가하는 플레이어(Mid-session Join)는 **BB 포지션이 돌아올 때까지 대기**하거나, 동등한 BB 금액을 즉시 포스팅하고 참가할 수 있다.
- 칩이 BB 금액보다 적은 플레이어는 **올인 블라인드**로 처리된다.

### 토너먼트 블라인드 인상 (Tournament Mode, 선택 적용)

- 기본 모드는 캐시 게임 (블라인드 고정).
- 토너먼트 모드 활성화 시 서버가 **레벨별 인상 스케줄**을 관리한다.

| 레벨 | SB | BB | 앤티 |
|------|----|-----|------|
| 1 | 10 | 20 | 0 |
| 2 | 15 | 30 | 0 |
| 3 | 25 | 50 | 0 |
| 4 | 50 | 100 | 10 |
| 5 | 75 | 150 | 15 |
| 6+ | ×2 매 레벨 | ×2 매 레벨 | BB의 10% |

## 3. Betting Rules (베팅 규칙)

### 허용 베팅 모드

- **No-Limit (기본)**: 레이즈 상한 없음. 최소 레이즈 = 직전 레이즈 증분 이상.
- **Pot-Limit (선택)**: 최대 레이즈 = 현재 팟 크기.
- **Fixed-Limit (선택)**: 프리플랍·플랍은 BB 단위, 턴·리버는 BB×2 단위로 고정. 라운드당 최대 4번 레이즈.

### 허용 베팅 액션

| 액션 | 조건 |
|------|------|
| Fold | 언제든지 가능. 핸드 포기. |
| Check | 현재 라운드 추가 베팅이 없을 때. BB는 프리플랍에서 체크 가능 (콜 없을 시). |
| Call | 현재 최고 베팅 금액까지 칩을 일치시킨다. |
| Raise | 현재 최고 베팅에 최소 증분 이상을 추가한다. |
| All-In | 보유 칩 전부를 베팅한다. 부족해도 콜·레이즈 의사로 처리. |

- **하프/따당/하우스룰은 미지원** — 위 5가지 액션만 허용.
- **스트링 베팅 금지**: 레이즈 금액은 한 번에 선언·전송해야 한다.

### 4라운드 진행 순서

#### 프리플랍 (Pre-Flop)

1. 딜러가 각 플레이어에게 홀 카드 2장을 순서대로 배분한다.
2. SB·BB 강제 포스팅.
3. **UTG부터 시계 방향** 베팅 진행. BB가 마지막.
4. 레이즈 없이 BB까지 모두 콜/폴드한 경우, BB에게 **옵션(Option)** 권한 부여 — 추가 레이즈 또는 체크 선택.

#### 플랍 (Flop)

1. 번 카드(Burn Card) 1장 제거 후 커뮤니티 카드 3장 공개.
2. **SB부터 (폴드 시 살아있는 첫 번째 플레이어부터)** 시계 방향 베팅.
3. 베팅 미발생 시 모두 체크 가능.

#### 턴 (Turn)

1. 번 카드 1장 제거 후 커뮤니티 카드 1장 추가 공개.
2. 플랍과 동일 순서로 베팅.
3. Fixed-Limit 모드: 이 라운드부터 베팅 단위 2배 적용.

#### 리버 (River)

1. 번 카드 1장 제거 후 커뮤니티 카드 1장 추가 공개 (총 5장).
2. 턴과 동일 순서로 베팅.
3. 베팅 완료 후 쇼다운 진입.

### 최소 레이즈 규칙

- No-Limit / Pot-Limit: 최소 레이즈 증분 = **직전 레이즈(또는 오픈 베팅) 증분**과 동일.
  - 예) BB=20 → 최초 레이즈는 최소 40 (증분 20). 다음 레이즈는 최소 60 (증분 20 이상).
- Fixed-Limit: 정해진 단위로만 레이즈 가능.
- 올인 금액이 최소 레이즈 미만인 경우: 그 올인은 **레이즈로 간주하지 않으며** 이전 레이즈 플레이어에게 재레이즈 권한이 열리지 않는다.

### 턴 타임아웃

- 서버는 플레이어당 **30초 행동 제한** 타이머를 관리한다.
- 타임아웃 시 서버가 **자동 폴드** 처리한다.
- 연결 끊김(disconnect) 발생 시 타임아웃 타이머를 이어서 적용한다.

## 4. All-In Handling (올인 처리)

### 올인 감지

- 서버는 플레이어의 베팅 액션 처리 시 **칩이 0에 도달하면 자동 올인 플래그**를 설정한다.
- 올인 플레이어는 이후 라운드에서 추가 베팅·레이즈·콜 행동을 수행하지 않으며, 쇼다운까지 **패시브(passive)** 상태로 남는다.

### 콜 금액 계산

- 콜 금액 = `min(현재 최고 베팅액 - 해당 플레이어의 현재 라운드 납입액, 해당 플레이어 잔여 칩)`
- 잔여 칩이 콜 금액보다 적으면 → **잔여 칩 전부** 투입, 올인 처리.

### 올인 후 행동 제한

- 올인 플레이어는 **카드를 유지**하며 쇼다운 자격은 있다.
- 단, 올인 금액을 초과하는 팟(사이드팟)에는 수급 자격이 없다.
- 올인이 아닌 플레이어끼리 추가 베팅이 발생하면 그 초과분은 **사이드팟**으로 별도 관리한다.

## 5. Side Pot Calculation (사이드팟 계산)

### 팟 구조

| 팟 종류 | 설명 |
|---------|------|
| Main Pot (메인팟) | 올인 금액까지 모든 플레이어가 기여할 수 있는 팟 |
| Side Pot 1, 2, … | 올인 플레이어의 한도를 초과한 베팅으로 생성. 해당 라운드 참가 플레이어만 수급 자격 |

### 사이드팟 생성 알고리즘

서버는 핸드 종료 시 다음 순서로 팟을 계산한다.

1. 각 플레이어의 **총 납입액(total_committed)** 목록을 수집한다.
2. 납입액을 **오름차순 정렬** 후 중복 제거 → 고유 레벨 목록 생성.
3. 레벨 0에서 시작하여 각 레벨 구간의 팟을 순서대로 계산한다:
   ```
   for each level L in sorted unique levels:
       contribution_per_player = L - prev_level
       eligible_players = players whose total_committed >= L
       pot_amount = contribution_per_player × len(eligible_players)
       assign pot_amount to a new sub-pot with eligible_players as winners
       prev_level = L
   ```
4. 폴드한 플레이어가 납입한 칩은 해당 시점의 팟에 포함된다 (수급 자격은 없음).

### 사이드팟 계산 예시

| 플레이어 | 납입액 | 잔여 칩 | 상태 |
|---------|--------|---------|------|
| A | 100 | 0 | 올인 |
| B | 300 | 0 | 올인 |
| C | 300 | 200 | 활성 |

```
레벨 100: A·B·C 각 100 → 메인팟 = 300 chips (A·B·C 모두 수급 가능)
레벨 300: B·C 각 200 → 사이드팟 = 400 chips (B·C만 수급 가능)
```

- A가 최강 핸드여도 메인팟(300)만 획득. 사이드팟(400)은 B·C 중 강한 쪽이 획득.

### 팟 배분 원칙

- 각 팟은 **해당 팟 수급 자격이 있는 플레이어** 중 최강 핸드 보유자에게 지급된다.
- 동점 시 해당 팟을 균등 분할하고, 홀수 칩은 버튼에 가장 가까운 플레이어에게 1칩 추가 지급한다.
- 팟 분배는 서버가 단독으로 계산하며 클라이언트는 결과만 수신한다.

## 6. Showdown (쇼다운)

### 쇼다운 진입 조건

- 리버 베팅 완료 후 2명 이상이 활성 상태인 경우.
- 1명을 제외한 모든 플레이어가 폴드한 경우: 즉시 팟 지급, 쇼다운 없음.

### 패 공개 순서

- **마지막 공격적 행동(레이즈·베팅)을 한 플레이어**가 먼저 공개한다.
- 공격적 행동 없이 체크로 마무리된 경우: **SB부터 시계 방향** 순서로 공개.
- 이미 공개된 핸드보다 약한 핸드를 가진 플레이어는 **머킹(Muck, 비공개 폴드)** 권리를 가진다.
  - 단, 올인 쇼다운(사이드팟 계산 필요) 시 머킹 불가 — 패를 반드시 공개해야 한다.

### 핸드 비교 (서버 전담)

서버는 다음 순서로 최강 5장 조합을 결정한다.

1. 각 플레이어의 홀 카드 2장 + 커뮤니티 카드 5장 → **7C5 = 21가지 조합** 중 최강 핸드 선택.
2. 핸드 등급 비교 (Royal Flush=9 … High Card=0).
3. 동일 등급 시 킥커 비교 (섹션 1 킥커 규칙 적용).
4. 핸드 비교 결과를 기반으로 각 팟의 수급 자격자 중 최강자에게 팟 지급.

### 타이 해소 (Tie Resolution)

- **완전 동점**: 커뮤니티 5장이 두 플레이어 홀 카드보다 강한 경우 → 보드 플레이 (Chop Pot).
- **부분 동점**: 동점 플레이어 수로 팟을 균등 나눔.
- **홀수 칩 잔여분**: 버튼 포지션에 가장 가까운 시계 방향 플레이어에게 1칩 지급.

### 스플릿 팟 (Split Pot) 조건

- 5장 최강 조합이 두 플레이어 이상에서 **동일**한 경우.
- 예외: 보드(커뮤니티 카드) 5장 자체가 최강 핸드이고 홀 카드가 영향을 주지 않는 경우 → 해당 팟 수급 자격자 전원 균등 분배.

### 쇼다운 후 처리

1. 서버가 팟 배분 결과 메시지를 모든 클라이언트에 브로드캐스트한다.
2. 칩이 0인 플레이어는 **즉시 게임 아웃(Bust-out)** 처리된다.
3. 딜러 버튼이 시계 방향 이동 후 다음 핸드를 시작한다.
4. 활성 플레이어가 1명만 남으면 해당 플레이어가 최종 우승자로 결정된다.
