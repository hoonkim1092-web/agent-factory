# Decision: Rule baseline selection for poker

- **Date**: 2026-05-08
- **Status**: Accepted

## Decision
World Series of Poker (WSOP) 공식 텍사스 홀덤 룰셋을 8인 네트워크 플레이 포커 게임의 규칙 기준선으로 채택한다.

## Alternatives Considered
1. **Poker TDA (Tournament Directors Association) 룰셋** — 토너먼트 운영에 최적화되어 있으나, 캐주얼 캐시 게임과의 규칙 차이가 크다는 단점 존재
2. **HWAIN 국내 온라인 포커 서비스 룰** — 한국 사용자 친화적 용어 체계를 제공하나, 국제 공신력 및 공개 문서화 수준이 낮다 (web_002)
3. **홈 게임 변형 룰 (House Rules)** — 구현 자유도가 높으나, 표준화 부재로 멀티플레이어 간 규칙 분쟁 위험이 높다

## Rationale
- WSOP 텍사스 홀덤은 세계에서 가장 널리 통용되는 포커 표준으로, 핸드 랭킹·베팅 구조(블라인드·앤티·포지션)·쇼다운 규칙이 공개 문서로 명확히 정의되어 있다 (web_001, web_003)
- 8인 테이블 구성(최대 9인 홀덤 테이블 규격 내)은 WSOP 표준 내에서 직접 지원되므로 별도 규칙 확장 없이 적용 가능하다
- 국내 사용자 대상 한국어 용어 정리(web_001)가 풍부하게 존재하여 UI 레이블·오류 메시지 현지화 비용을 절감할 수 있다
- 공신력 있는 공개 PDF 기반 규칙 문서(web_003)가 존재하여 규칙 엔진 구현 시 명세 추적이 가능하다
- 침착맨 등 국내 인지도 높은 콘텐츠(web_004)도 동일 텍사스 홀덤 룰을 기반으로 하여, 한국 사용자층의 규칙 친숙도가 높다
