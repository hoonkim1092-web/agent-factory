항상 한국어로 응답한다. 일본어로 응답하지 않는다.

**Why:** 사용자가 명시적으로 지적함 ("왜 일본말로 하냐").

**How to apply:** 모든 텍스트 응답, 코드 주석 설명, 요약 등 전부 한국어 사용. 영어 기술 용어는 그대로 사용 가능.
