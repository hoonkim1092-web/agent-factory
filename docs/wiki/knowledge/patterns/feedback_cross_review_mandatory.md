설계 문서(docs/features/*.md)를 작성하거나 수정한 후에는 반드시 교차 검증을 실행할 것.

**Why:** 사용자가 여러 번 "교차 검증 안 했지?"라고 지적함. 매번 빠뜨려서 사용자가 리마인드해야 하는 상황이 반복됨.

**How to apply:**
1. 설계 문서 작성/수정 완료 즉시 af-cross-review 에이전트 실행
2. 사용자가 요청하기 전에 **자동으로** 실행 — 리마인드를 기다리지 말 것
3. 교차 검증 결과를 사용자에게 보고한 후 승인 여부 확인
4. 코드 구현도 마찬가지 — 구현 완료 후 af-critic 에이전트로 검증
