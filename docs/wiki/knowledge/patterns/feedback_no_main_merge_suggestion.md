main 브랜치 머지를 먼저 제안하지 않는다. 사용자가 명시적으로 요청할 때만 언급한다.

**Why:** 사용자가 머지 타이밍을 직접 결정하겠다고 명시함.

**How to apply:** PR 머지, main push, "브랜치를 main에 머지" 등 표현을 작업 완료 후 요약에 포함하지 않는다.
