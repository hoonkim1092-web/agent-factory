설계/논의/리뷰/멀티라운드 deliberation은 Opus 4.7로 진행하고, 실제 Phase 코드 구현 단계로 넘어갈 때는 Sonnet 4.6으로 전환한다.

**Why:** 사용자가 2026-05-01 명시적으로 "구현할 때는 소넷으로 전환해"라고 지시. Opus는 설계 품질·합의 도출이 강하지만 토큰 비용이 높고, 구현(파일 편집·테스트 실행·디버그)은 Sonnet으로 충분하면서 비용 효율이 훨씬 좋다.

**How to apply:** 
- 모델 전환은 사용자만 가능 (`/model claude-sonnet-4-6` 또는 `/config`). 내가 직접 바꿀 수 없음.
- 단계 전환 시점이 오면(설계 합의 완료 → 코드 PR 시작) 사용자에게 명시적으로 "구현 단계로 넘어갑니다, /model로 Sonnet 전환하세요"라고 안내한다.
- 역방향(설계 회귀 필요)이 발생하면 Opus 복귀 권장.
- 같은 세션 안에서 토론과 코드 작성이 섞이면 비용이 커진다 — 가능한 단계 단위로 분리.
