커밋/푸시 완료 후 또는 작업 단위가 끝났을 때 메모리 동기화를 자동으로 실행할 것.

**Why:** 사용자가 매번 "메모리동기화"를 직접 요청해야 하는 상황이 반복됨. 교차 검증과 마찬가지로 사용자가 리마인드하지 않아도 자동으로 수행해야 함.

**How to apply:**
1. 커밋+푸시 완료 직후 → `project_pending_work.md` + `MEMORY.md` 자동 업데이트
2. 새 feedback/project 메모리가 생겼으면 → `MEMORY.md` 인덱스에 즉시 반영
3. 세션 마무리 분위기일 때 → 완료/미완료 작업 정리하여 메모리 동기화
4. 사용자가 요청하기 전에 **자동으로** — 리마인드를 기다리지 말 것
