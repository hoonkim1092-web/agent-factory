**규칙 1:** 구현은 Sonnet (현재 모델)이 담당, 설계 문서는 Opus 4.7 (1M context)이 담당.

**규칙 2:** 사용자가 한 번 방향을 승인했으면 (a)/(b)/(c) 옵션 나열로 다시 묻지 말 것. 가장 현실적인 권고를 정한 뒤 즉시 실행.

**Why:** 매 단계 (a)(b)(c) 선택지를 다시 묻는 것은 마찰만 만들고 진척을 늦춤. 사용자가 명시적으로 "권한 줬잖아 퍼미션 스킵하라고 왜 자꾸 묻지"라고 지적함 (2026-04-30).

**How to apply:**
- 구현 작업 → Sonnet 세션에서 직진
- 설계 문서 (docs/YYYY-MM-DD-*.md) → Opus 세션 권장
- 방향 합의 후에는 옵션 나열 대신 "X부터 시작합니다" 식 단언 후 실행
- 위험·되돌리기 어려운 작업(force push, DB drop 등)에만 확인 받기
