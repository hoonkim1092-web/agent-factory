type: feedback
---

자동 생성 파일이라도 의미 있는 파일은 반드시 커밋해야 한다. 테스트 임시 파일만 제외.

**Why:** 커밋을 안 하면 집 PC에서 pull 받을 수 없어 같은 작업을 다시 하게 됨. 실제로 syncCompyne/*.py, codex_chat/*.json 등이 미커밋 상태로 남아 집 PC에서 받지 못한 사례 발생.

**How to apply:** 세션 끝나기 전 git status 확인하고, 의미 있는 변경 파일은 모두 커밋. 자동 생성이더라도 스킬 레지스트리, 동기화 스크립트, 메모리 파일 등은 커밋 대상.
