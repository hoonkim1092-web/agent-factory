### 스킬 자동 품질 감사 (백그라운드)

`SkillSelfEvolutionHook` (실행 우선순위=80):
- 에이전트 10회 실행마다 → `bulk_enrich_all_skills(max_skills=5)`
- 품질 점수 < 0.5인 스킬 자동 메타데이터 개선
- 백그라운드 스레드에서 실행 (메인 파이프라인 블로킹 없음)

**품질 점수 공식:**
```

when_to_use         +0.20
keywords            +0.20
semantic_tags       +0.20
category(비기본값)   +0.10

──────────────────────────
최대                  1.0
```

### 자동 코드 리뷰 + 문서 업데이트 (백그라운드)
