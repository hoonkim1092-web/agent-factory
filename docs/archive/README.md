# Docs Archive

이 폴더는 현재 실행 기준 문서가 아닌 과거 설계안, 스냅샷 리뷰, 해결 완료 리포트를 보관한다.

운영 규칙:

- 현재 기준 문서는 `docs/`, `docs/features/`, `docs/plans/`, `docs/work-items/`, `docs/code_review/code-review.md`에 둔다.
- `docs/code_review/code-review.md`는 살아있는 문서이므로 archive로 옮기지 않는다.
- 대체 문서가 명시된 초안, 날짜형 스냅샷, 해결 완료 리포트는 archive로 이동한다.
- archive 문서는 자동 설계 리뷰와 컨텍스트 동기화의 기본 대상에서 제외한다.

하위 폴더:

- `superseded/`: 더 최신 버전으로 대체된 설계 초안
- `code_review/`: 과거 코드 리뷰 스냅샷과 검토 리포트
- `resolved/`: 의사결정 완료 또는 해결 완료된 문서
- `plans/`: 현재 실행 기준이 아닌 과거 계획/메모
- `reviews/`: 과거 자동 설계/코드 리뷰 산출물
- `research/`: 과거 비교 조사와 외부 프로젝트 흡수 분석
- `implementation/`: 완료된 구현 보고서와 작업 상태 기록
- `vision/`: 현재 운영 기준 문서는 아니지만 보존 가치가 있는 장기 비전/박제 명세
