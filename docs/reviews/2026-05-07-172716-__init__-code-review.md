#### 1. [ACCEPT] [Critical] Frozen-build: `_PACKS_DIR` uses `__file__` without frozen guard
- **Critic**: "`_PACKS_DIR = Path(__file__).parent / "packs"` — PyInstaller frozen에서 `packs/`가 존재하지 않아 모든 팩이 누락, `checklist` 비어 `QualityContractBuildError` 발생"
- **Cross**: "`_load_pack()` returns `[]` when files missing, `build()` raises on empty checklist at `quality_contract.py:119-123`"
- **Judgment**: 양쪽 모두 동일 코드 경로(`quality_contract.py:66-67`)를 독립적으로 추적해 동일한 런타임 실패를 확인. `code-review.md` AF-Specific 패턴과 일치.
- **Action Required**: `quality_contract.py:67` 교체:
  ```python
  import sys as _sys
  if getattr(_sys, "frozen", False):
      _PACKS_DIR = Path(_sys._MEIPASS) / "core" / "research" / "packs"
  else:
      _PACKS_DIR = Path(__file__).parent / "packs"
  ```
